# Outdoor Free Gym App

## Overview

Outdoor Free Gym App is a full-stack web platform designed to help residents and travelers discover free outdoor fitness facilities while enabling municipal organizations to manage gym listings, equipment inventories, and maintenance requests.

## Core Features

- **Interactive Gym Map:** Discover outdoor fitness areas based on location.
- **Equipment Inventory:** View available equipment, quantities, and conditions.
- **User Reviews:** Submit ratings, feedback, and photos.
- **Maintenance Requests:** Report damaged equipment and track repair status.
- **Municipal Dashboard:** Allow authorized municipal administrators to manage gym listings and maintenance.
- **Data Reporting:** Export equipment and maintenance data for analysis.

## Proposed Tech Stack

- **Frontend:** React.js
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL (raw SQL, no ORM)
- **Maps:** OpenStreetMap with Leaflet
- **Deployment:** Docker and cloud hosting
- **Version Control:** Git and GitHub

## Database Entities

1. Users
2. MunicipalEntities
3. OutdoorGyms
4. EquipmentInventory
5. ReviewsAndRatings
6. MaintenanceRequests

Database tables will be normalized according to the project's requirements.
